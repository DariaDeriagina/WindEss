# 🚴‍♀️ WindEss Rides & Parks

**WindEss** is a prototype web application for Windsor & Essex County cyclists and families.  
It helps users **discover local parks, plan rides, and explore bike-friendly routes**.

This project is built in **React** as part of a learning + portfolio project, inspired by real community cycling initiatives.

---

## ✨ Features (so far)

- 📱 Mobile-style UI with app-like frame
- 🔍 Park Search with filters (bike, waterfront, playground, picnic)
- 🏞 Park Cards with images + activity badges
- 📌 Scrollable list of local Windsor & Essex parks
- 🧭 Bottom navigation bar (Home, Favorites, Parks & Rides, About)
- 🛠 Planned: “Get Route” screen with map & directions (GraphHopper/OSRM backend)

---

## 🛠 Tech Stack

- **React.js** (UI components & state management)
- **Framer Motion** (animations, landing screen effects)
- **Java (planned)** backend for routing (GraphHopper/OSRM)
- **HTML/CSS/JS** basics
- **GitHub** for version control & collaboration
